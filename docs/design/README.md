# Design｜架构与接口

模板通过统一入口和轻量 Python package 验证软件配置与证据收据；没有真实科研算法。科研项目应按需补充模块、技术路线、原因、替代方案、限制及重要设计决策。ADR 是可选，不为文件形式增加负担。

## 本模板契约

`configs/smoke.toml` 使用 kind=software-smoke、整数 schema_version=1；V0.1 无版本输入兼容，未知字段或版本拒绝。配置读取与指纹基于同一字节。doctor/smoke/audit 仅软件级，使用 JSON 收据；无安装的日常检查；reproduce 未配置时非零退出。源码与 [测试](../../tests) 提供可运行契约。

## 真实项目（适用时）

多人依赖的接口记录字段、维度、单位、坐标系、时间、版本、有效值、失败行为与兼容性，并执行契约及下游测试；后端不支持的能力显式报错。区分 Mock、运动学、动力学、真实硬件；默认预检不建立真机连接，验证停止、超时和资源清理。复用公共逻辑，适配层轻量。关键架构变更记录原因与对照验证，不复制源码形成第二权威。
