# 服务器权限与工作区

**当前为协商阶段：不实施新的 ACL、chmod、chown、sudo、账户权限或自动发布配置；现有安全规则继续有效。** 普通成员与具有管理员权限的成员均依靠自觉，不擅自改变共享源码、公共环境、系统配置、资产、他人进程与实验数据。

- 正式源码：组织 GitHub main。
- 正式运行：/home/shared/<repository-name>-published/current（以实际服务器路径为准）。
- 个人开发：$HOME/<repository-name>，从 Git 获取源码并在独立功能分支开发，PR 验收后合并。
- 原有共享开发目录保留，不覆盖、移动、重置或删除。
- 实验、缓存、日志、视频和权重写入个人目录或团队指定数据区，不写入 published 或公共环境；不抢占其他成员资源。

## 待协商确定后实施

服务器管理员设置 published 和公共环境为普通成员可读、可进入、可执行但不可写；仅指定发布或环境维护者具有必要写权限。管理权限按职责与最小权限分配，普通科研开发和系统管理分离；不因本稿回收任何现有权限。

由管理员配置受控 Git main 到 published 的同步发布，普通成员只使用，不直接 git pull 或修改正式快照。发布维护者及环境维护者待确认。权限变更前验证兼容性，防止破坏现有实验，并记录回滚方案。见 [RELEASE](RELEASE.md)。

本文件只定义建议和自觉约定，不代表已配置服务器。
