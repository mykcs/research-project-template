# Wish｜原始意图

建立现代、简洁、可靠的科研工程与交接体系：让没参与过项目的新同学能独立理解现状、运行实验、继续开发；个人充分利用 Agent，多人合作加强提交与合并审阅；共享大型环境但隔离个人实验；独立任务成熟后集成；区分软件验证与真实科研证据。

**守住真实目的，统一核心源码位置。** 一个模板允许独立 Code、独立 Website 和综合 Project；同一项目优先同仓，独立产品、权限、维护或发布边界允许分仓。非网站业务代码集中在 `src/`，综合项目的附属网站集中在 `website/`，独立网站可使用根 `src/` 或 `website/` 子树。其余形式按任务需求选择。不为目录整齐增加空文件，不因追求速度牺牲科研严谨性。未来希望支持工程型项目和提出、检验科学假设的研究型项目，用实际交接反馈迭代模板。未立项方向保留于此，转为明确验收任务后进入 Task。Wish 可按项目需求省略。
